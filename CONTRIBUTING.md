# Contributing

## Use of Generative AI

FNF-LOVE-NeonCadence permits contributions made with large language models
(LLMs) and other AI assistants. Human contributors remain responsible for the
correctness and quality of everything they submit. Using AI tools is optional.

For every LLM-assisted contribution, the submitting human must review the full
diff and write an explanation in their own words in the pull request description
(or accompanying commit message when contributing without a pull request).
Explain what changed, why it was needed, how it works, how it was checked, and
any known limitations or tradeoffs. State which checks were not performed.

An LLM-generated explanation or copied output does not meet this requirement.
Contributors must be able to answer follow-up questions about their changes.
Contributions without a satisfactory human-written explanation must not be
accepted until the contributor demonstrates understanding.

See [AGENTS.md](AGENTS.md) for the full policy and guidance for AI assistants.
This policy applies to this fork; contributions to the upstream project must
follow its own rules. All applicable copyright notices and license terms remain
in effect.
